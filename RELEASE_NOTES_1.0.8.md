# Aura 1.0.8

Статус: локальная release-сборка готова, внешняя публикация не выполнялась.

## Главное

- Потоковый локальный ввод для Sherpa-ONNX Parakeet TDT v3: 16 kHz mono audio доставляется событийными чанками через bounded-очередь, а VAD ограничивает повторное распознавание активным речевым сегментом.
- Постоянное локальное WebSocket-соединение, функциональный прогрев inference и одна контролируемая попытка восстановления после сбоя sidecar.
- CUDA и DirectML-компоненты загружаются по требованию с проверкой размера и SHA-256; при несовместимом GPU Aura автоматически переходит на CPU.
- Адаптивная частота preview снижает нагрузку при отставании decoder. Десятиминутные synthetic-тесты подтверждают ограниченный рост памяти.
- Подтверждённые endpoint-сегменты теперь синхронизируют регистр и пунктуацию во время пауз, поэтому финал обычно исправляет только активный хвост, а не перепечатывает весь длинный текст.

## Надёжность и безопасность

- Полный WAV остаётся авторитетным fallback при разрыве сокета, queue gap, пустом/сомнительном endpoint или stale session.
- WAV пишется инкрементально через RAII `.partial`-файл: commit атомарен, отмена и ошибка удаляют незавершённый файл.
- Исправлены anti-aliasing ресемплера, обработка non-finite samples и дренирование хвоста записи.
- Sidecar проверяется на готовность, GPU→CPU fallback не блокирует интерфейс, дочерние процессы привязаны к жизненному циклу приложения.
- API-ключи и история защищены Windows DPAPI; frontend получает только redacted metadata. Настройки и Tauri capabilities следуют least-privilege модели.
- Focus, generation и physical-edit guards запрещают опасные Backspace-коррекции после смены окна, ручного редактирования или Undo. Финальный текст сохраняется в history и clipboard.
- Частичный WinAPI `SendInput` больше не считается успехом; внутреннее зеркало обновляется только по фактически применённому replacement plan.

## Проверка

- Rust: 85/85 тестов, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`.
- Frontend: lint, TypeScript и 10/10 static tests, включая все локализации и согласованность версии.
- Dependency audit: npm — 0 vulnerabilities; RustSec — 0 vulnerabilities и 18 разрешённых предупреждений о транзитивных unmaintained/target-specific пакетах.
- Ручная CUDA streaming-диктовка на NVIDIA прошла без queue gaps и reconnect; постоянный socket сохранился на протяжении длинной сессии.

## Известное поведение

- Parakeet TDT v3 остаётся offline-моделью с simulated streaming: сервер получает целиком только текущий VAD-сегмент, а не аудио всей сессии.
- Если достоверность streaming-результата снижена, полный WAV fallback намеренно увеличивает время финализации ради сохранения текста.
- При ручном изменении live-текста Aura прекращает destructive reconciliation и копирует итог в буфер обмена; автоматическое восстановление удалённой пользователем части не выполняется.
- Артефакты не подписаны Authenticode, поэтому Windows SmartScreen может показать предупреждение.
