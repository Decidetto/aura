## Находки (по приоритету)

### Важно

**C1. Коммит-мусор «// Тtodo: no.» в lib.rs**
1252 строки спам-комментариев «// Тtodo: no.», внесённые коммитом `121c25a` (amend), зона строк 3179–4429. Код не пострадал (0 удалений), файл вырос 5423 → 6675 строк, 215 функций, сборка и 112 тестов проходят. Сообщение коммита не соответствует содержимому.
- Можно: пересобрать коммит без спама (amend-историю менять осознанно) или сразу отдельным чистым коммитом.

**C2. Ошибка `Access forbidden (403)` без перевода в overlay**
12 из 13 русских строк ошибок Rust переведены в `overlay.js` (errorTranslations), ключ «Access forbidden (403): ...» отсутствует → fallback на английский во всех 9 локалях. Ключ есть в lib.rs.

**F1/Ann. `Cloud unavailable — used local model instead` не локализован**
Строка присутствует в lib.rs, но отсутствует и в overlay.js, и в main.js (`noticeTransformers` переводит только `final-copied-after-edit`). Показывается по-английски во всех локалях, включая ru.

**D1. Полная перерисовка истории при каждой записи**
`updateHistoryPanel`/`historyPanel` перерисовывается целиком на каждый insert вместо инкрементальной вставки → O(n²) DOM-работы на больших историях. Ресурс: заменить на insertAdjacentHTML в конец списка.

### Важно/Мелочь (TBC)

**C3. Мёртвый fallback в селект-превью**
В `SELECT_PREVIEW_DEFS` (main.js:2510–2513) `select-ui-lang` ссылается на `defaultKey: "ui_lang"`, `select-language` — на `fallbackKey: "lang_forced"`; обоих ключей нет в `SELECT_PREVIEW_TEXTS` (11 ключей: engine_whisper, engine_parakeet, lang_auto, lang_layout, provider_gemini, provider_openai, provider_groq, theme_zen, theme_rhodes, theme_scifi, theme_classic). `selectPanelCaption` (main.js:1568–1577) возвращает пустую подпись. Решение: вернуть ключи либо удалить мёртвый код.
— В vault записей по этому решению НЕТ: «ничего не записано».

### Мелочь

- **C4.** `allowedSpecialKeys` объявлен (main.js:1992), нигде не используется.
- **C5.** `setDocumentLanguage` экспортируется из ui-accessibility.js, не вызывается (lang ставит main.js).
- **C6.** Кнопки модальных окон наследуют глобальные `.btn-secondary` margin-top:12px / align-self от страницы — **известный баг**, зафиксирован в vault (memory 2026-08-08); фикс (margin:0 + align-self:stretch) уже внёсён, требует визуальной проверки.
- **C7.** Код ссылается на id облачных провайдер-панелей, отсутствующие в index.html (карточка «Облако» убрана) — потенциальные null-обработки; требует ручной проверки (TBC).
- **C8.** `saveSettings` (main.js:2433): `api_provider: selectProvider.value,` — сломанный отступ (косметика).
- **C9.** Кнопки «скопировать всю историю» нет (ни в HTML, ни в JS); копирование — только по элементам.
- **C10.** Неровные отступы в index.html (строки 53, 83, 110, 136, 192, 399, 448, 500, 515).
- **C11.** Окно main: transparent:true + decorations:false — накладные расходы композитинга; осознанное «стеклянное» окно — ок, но можно закрыть «ложным» вложенным окном без прозрачности.
