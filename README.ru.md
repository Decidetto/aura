Зажмите горячую клавишу, надиктуйте текст и отпустите — Aura мгновенно расшифрует речь и напечатает готовый текст прямо под курсором в **любом** приложении Windows. Работает автономно и приватно на локальных нейросетях (Whisper, NVIDIA Parakeet с аппаратным ускорением на GPU CUDA) или через облачные сервисы (Gemini, Groq, OpenAI, Hugging Face, Custom API).

**100% бесплатно и с открытым исходным кодом (AGPL-3.0)** — без подписок, скрытых ограничений, встроенной рекламы и телеметрии.

## Возможности

- **Диктовка по глобальной горячей клавише** — удерживайте для записи (`Alt+V`) или включите режим переключателя (короткое нажатие); отмена по `Esc`.
- **Два режима распознавания**:
  - **Локальный (100% офлайн и приватно)** — сайдкар whisper.cpp (CPU) или NVIDIA Parakeet TDT v3 (sherpa-onnx). Звук не покидает ваш компьютер; модели скачиваются в один клик прямо из настроек.
  - **Облачный** — Google Gemini, Groq, OpenAI, Hugging Face или собственный OpenAI-совместимый сервер.
- **Аппаратное ускорение NVIDIA CUDA** — поддержка GPU для модели Parakeet с автоматической загрузкой runtime-библиотек и переключением на CPU при необходимости.
- **Мгновенный потоковый ввод** — стабильный пословный ввод текста в реальном времени без мерцания и дублирования.
- **Защита фокуса (Focus Guard)** — гарантирует, что надиктованный текст никогда не напечатается в неактивное окно при случайной смене фокуса.
- **История транскрипций** — последние 50 записей со строкой живого поиска, фильтрацией по источникам (`Все` / `Локально` / `Облако`) и копированием в один клик.
- **Собственный словарь** — подсказка специфических имен, брендов и технических терминов для безошибочного написания.
- **11 вариантов языка** — автоопределение, привязка к текущей раскладке клавиатуры или фиксированный выбор (ru, en, de, es, fr, it, zh, pt, tr).
- **Компактный оверлей** — индикация уровня микрофона, таймер записи, звуковые темы (Дзен, Rhodes, Sci-Fi, Классика) и гибкая настройка отображения.
- **Удобство и безопасность** — автозапуск с Windows, меню в системном трее, системное шифрование ключей (DPAPI) и встроенная выгрузка диагностического отчета.

## Сравнение

Aura сочетает автономную скорость локальных нейросетей, поддержку GPU-ускорения и гибкость подключения облачных сервисов.

| Параметр | **Aura** | **Handy** | **Wispr Flow** |
|---|---|---|---|
| **Стоимость** | **Бесплатно (AGPL-3.0)** | Бесплатно (Open Source) | Платно (подписка) |
| **Платформы** | Windows *(macOS в разработке)* | Windows / macOS / Linux | Windows / macOS |
| **Локальные модели (Офлайн)** | **✅ Whisper & Parakeet (CUDA GPU / CPU)** | ✅ Whisper / Parakeet | ❌ Только облако |
| **Облачные провайдеры** | **✅ Gemini, Groq, OpenAI, HF, Custom** | ❌ | ✅ Собственное облако |
| **Потоковый ввод в реальном времени** | **✅** | ❌ | ✅ |
| **Защита фокуса (Focus Guard)** | **✅** | ❌ | ➖ |
| **Шифрование данных (DPAPI)** | **✅** | ❌ | ➖ |
| **Пользовательский словарь терминов** | **✅** | ❌ | ✅ |
| **История с поиском и фильтрацией** | **✅** | ❌ | ✅ |

> Честные компромиссы: официальные сборки Aura пока доступны только для Windows 10 и 11 (порт для macOS уже в кодовой базе). Handy — зрелое кросс-платформенное решение. Wispr Flow предлагает вылизанный интерфейс, но работает исключительно через платную подписку и закрытое облако.

## Установка

Скачайте установщик из [Releases](https://github.com/malashkadev/aura/releases) и запустите. Ознакомиться с интерактивным макетом настроек и посмотреть демонстрацию работы можно на [Официальном сайте](https://aura-beryl-five.vercel.app/).

Для локального режима скачайте подходящую модель прямо из вкладки «Голос» в настройках программы (модель `Base` — отличный старт для быстрого CPU-распознавания). Для облачного режима укажите API-ключ выбранного сервиса (у Groq и Google Gemini доступны бесплатные лимиты).

> **При первом запуске «Система Windows защитила ваш компьютер»?** Установщик пока не подписан платным сертификатом Authenticode (он стоит несколько сотен долларов в год), поэтому SmartScreen предупреждает о новых программах. Нажмите **«Подробнее» → «Выполнить в любом случае»**. Исходный код полностью открыт и доступен для независимого аудита и самостоятельной сборки.

## Использование

| Действие | По умолчанию |
|---|---|
| Начать запись | зажать `Alt + V` |
| Завершить и напечатать текст | отпустить клавишу |
| Режим переключателя (фиксация записи) | короткое нажатие `Alt + V` |
| Отменить запись | `Esc` |

Горячая клавиша, язык, движок и параметры оверлея настраиваются в окне настроек (иконка в трее → «Открыть настройки»).

## Сборка из исходников

Требования: [Rust](https://rustup.rs/) (stable), [Node.js](https://nodejs.org/) 18+, WebView2 (встроен в Windows 10/11).

```bash
git clone https://github.com/malashkadev/aura.git
cd aura
npm install
npm run dev     # режим разработки
npm run build   # установщик NSIS/MSI в src-tauri/target/release/bundle/
```

Бинарники whisper.cpp находятся в `src-tauri/binaries/`. Для обновления до свежего релиза выполните `python install_whisper.py`.

Запуск тестов:

```bash
cd src-tauri
cargo test
```

## Приватность и безопасность

- **Локальный режим** работает полностью автономно на вашем компьютере (CPU / GPU) и не передаёт аудиозаписи в сеть.
- **Облачный режим** отправляет аудио, полученный транскрипт, выделенный текст (только при включённом редактировании выделения) и словарь терминов напрямую выбранному провайдеру по TLS без сторонней телеметрии или аналитики.
- **Безопасное локальное хранение** — API-ключи и история транскрипций шифруются с помощью **Windows DPAPI** (`CryptProtectData`), а доступ к файлам изолирован на уровне ACL для текущего пользователя и SYSTEM.
- **Проверка обновлений** выполняется вручную или только при её явном включении в настройках.

## Недавно добавлено

- **Аппаратное ускорение NVIDIA CUDA** — перенос инференса локальной нейросети Parakeet на GPU с загрузкой библиотек по требованию и автоматическим откатом на CPU.
- **5-вкладочный интерфейс настроек** — организованные разделы параметров («Основные», «Голос», «Управление», «История», «О программе»).
- **История с поиском и фильтрами** — быстрый поиск по надиктованному тексту и разделение на Local / Cloud.
- **Шифрование Windows DPAPI** — системная защита конфиденциальных ключей и истории со строгими правами доступа.
- **Потоковый ввод и Focus Guard** — пословный ввод без мерцания и защита от печати в чужие окна.
- **Кастомные доступные селекты** — стильные анимированные меню с отслеживанием прокрутки и поддержкой клавиатурной навигации.
